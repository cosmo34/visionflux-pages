Assistance — Oculus

Oculus est un studio vidéo natif pour Mac : capture, diffusion live, montage et conversion dans une seule application, optimisée pour Apple Silicon.

Contact

Support et problèmes techniques : contact@picaza.fr

Précisez votre version d’Oculus, la version de macOS et une description du problème. Joignez les journaux de diagnostic si possible (voir ci-dessous).

Configuration minimale

  • macOS 14.0 (Sonoma) ou ultérieur
  • Mac avec processeur Apple Silicon (M1 ou ultérieur)
  • Périphérique de capture compatible AVFoundation (UVC, caméra intégrée, nombreuses cartes externes)

Démarrage rapide

  1. Connectez votre source vidéo (et audio si besoin).
  2. Autorisez l’accès Caméra, Microphone et, si vous utilisez la source Écran, Enregistrement de l’écran dans Réglages Système.
  3. Choisissez le dossier d’enregistrement et, si besoin, le dossier de transfert dans le panneau Réglages.
  4. Sélectionnez l’onglet souhaité (Capture, Diffusion, Montage ou Conversion).
  5. Vérifiez l’aperçu, puis lancez l’action (REC, Diffusion ON, conversion, etc.).

Fonctionnalités par onglet

Capture

  • Sources : caméra USB/HDMI, capture d’écran, flux réseau (RTSP, RTMP, HTTP, HLS…).
  • Enregistrement H.264, HEVC ou ProRes ; filtres image ; incrustations multi-calques.
  • Transfert automatique optionnel vers un second dossier.

Diffusion

  • Streaming RTMP/RTMPS vers YouTube, Twitch, Facebook, Vimeo, Kick, Instagram ou serveur personnalisé.
  • Pipeline indépendant de la capture ; effets instantanés ; enregistrement simultané possible.
  • Configurez serveur et clé de stream dans le panneau Diffusion.

Montage

  • Timeline multi-pistes ; glisser-déposer de médias ; transitions et animations.
  • Export vers les formats de livraison configurés.

Conversion

  • Conversion par lots vers MP4, MOV, M4V, ProRes, MKV, AVI, AV1, etc.
  • Ajoutez des fichiers ou un dossier entier ; choisissez format, résolution et destination.
  • Version gratuite : 3 vidéos max, 2 minutes chacune (abonnement Conversion pour illimité).

Abonnements

Les abonnements sont gérés par le Mac App Store. Vous pouvez souscrire par onglet (Capture, Diffusion, Montage, Conversion) ou choisir l’accès Complet. Restaurez vos achats depuis la feuille d’abonnement si nécessaire.

Permissions macOS

  • Caméra / Microphone — capture et enregistrement audio.
  • Enregistrement de l’écran — source « Écran » uniquement.
  • Fichiers — dossiers choisis via les dialogues système (enregistrement, import, export).

Dépannage courant

  • Pas d’image : vérifiez le câble HDMI/USB, la source sur la régie, et sélectionnez le bon périphérique dans Oculus.
  • Source externe (Blackmagic, ATEM) : la résolution réelle suit le signal entrant ; les réglages HD/FHD/4K dans l’app n’imposent pas la résolution matérielle.
  • Diffusion bloquée : vérifiez la clé de stream, le protocole (RTMPS pour Twitch) et votre connexion réseau.
  • Conversion échouée : vérifiez l’accès au dossier de destination ; rouvrez-le via le panneau Conversion.
  • Dossiers vides dans la barre latérale : rouvrez le dossier via Réglages → Transfert / destination pour renouveler l’autorisation macOS.
  • Incrustation introuvable : si un fichier média a été déplacé, utilisez « Rechercher le fichier… » sur le calque concerné.

Journaux et rapports

  • Menu Aide → Ouvrir le dossier des journaux…
  • Menu Aide → Exporter les journaux de diagnostic… (également dans Réglages)
  • En cas de plantage, Oculus peut proposer d’envoyer un rapport par e-mail à contact@picaza.fr (facultatif ; confirmation dans Mail).
