Assistance — Oculus

Oculus est une application macOS pour l’aperçu et l’enregistrement de sources vidéo professionnelles (USB, HDMI, régie, etc.).

Contact

Support et problèmes techniques : contact@picaza.fr

Configuration minimale

  • macOS 14.0 (Sonoma) ou ultérieur
  • Mac avec processeur Apple Silicon (M1 ou ultérieur)
  • Périphérique de capture compatible AVFoundation (UVC, caméra intégrée, nombreuses cartes externes)

Démarrage rapide

  1. Connectez votre source vidéo (et audio si besoin).
  2. Autorisez l’accès Caméra et Microphone lorsque macOS le demande.
  3. Choisissez le dossier d’enregistrement et, si besoin, le dossier de transfert via le panneau Réglages.
  4. Vérifiez l’aperçu, puis lancez l’enregistrement avec le bouton REC.

Dépannage courant

  • Pas d’image : vérifiez le câble HDMI/USB, la source sur la régie, et sélectionnez le bon périphérique dans Oculus.
  • Source externe (Blackmagic, ATEM) : la résolution réelle suit le signal entrant ; les réglages HD/FHD/4K dans l’app n’imposent pas la résolution matérielle.
  • Dossiers vides dans la barre latérale : rouvrez le dossier via Réglages → Transfert / destination pour renouveler l’autorisation macOS.
  • Journaux : menu Aide → Ouvrir le dossier des journaux… ou Exporter les journaux de diagnostic….
  • Plantage : au redémarrage, Oculus peut proposer d’envoyer un rapport par e-mail à contact@picaza.fr (envoi facultatif, confirmation dans Mail).
