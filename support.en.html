Support — Oculus

Oculus is a native video studio for Mac: capture, live streaming, editing, and conversion in one application, optimized for Apple Silicon.

Contact

Technical support: contact@picaza.fr

Please include your Oculus version, macOS version, and a description of the issue. Attach diagnostic logs if possible (see below).

Minimum requirements

  • macOS 14.0 (Sonoma) or later
  • Mac with Apple Silicon (M1 or later)
  • Capture device compatible with AVFoundation (UVC, built-in camera, many external cards)

Quick start

  1. Connect your video source (and audio if needed).
  2. Allow Camera, Microphone, and if you use the Screen source, Screen Recording in System Settings.
  3. Choose the recording folder and, if needed, the transfer folder in Settings.
  4. Select the desired tab (Capture, Streaming, Editing, or Conversion).
  5. Check the preview, then start your action (REC, Streaming ON, conversion, etc.).

Features by tab

Capture

  • Sources: USB/HDMI camera, screen capture, network streams (RTSP, RTMP, HTTP, HLS…).
  • Recording in H.264, HEVC, or ProRes; image filters; multi-layer overlays.
  • Optional automatic transfer to a second folder.

Streaming

  • RTMP/RTMPS streaming to YouTube, Twitch, Facebook, Vimeo, Kick, Instagram, or a custom server.
  • Pipeline independent from capture; instant effects; simultaneous recording possible.
  • Configure server and stream key in the Streaming panel.

Editing

  • Multi-track timeline; drag-and-drop media; transitions and animations.
  • Export to your configured delivery formats.

Conversion

  • Batch conversion to MP4, MOV, M4V, ProRes, MKV, AVI, AV1, and more.
  • Add files or an entire folder; choose format, resolution, and destination.
  • Free version: 3 videos max, 2 minutes each (Conversion subscription for unlimited use).

Subscriptions

Subscriptions are managed by the Mac App Store. You can subscribe per tab (Capture, Streaming, Editing, Conversion) or choose Complete access. Restore purchases from the subscription sheet if needed.

macOS permissions

  • Camera / Microphone — capture and audio recording.
  • Screen Recording — “Screen” source only.
  • Files — folders chosen via system dialogs (record, import, export).

Common troubleshooting

  • No picture: check the HDMI/USB cable, the source on your switcher, and select the correct device in Oculus.
  • External source (Blackmagic, ATEM): actual resolution follows the incoming signal; HD/FHD/4K settings in the app do not override hardware resolution.
  • Streaming stuck: check your stream key, protocol (RTMPS for Twitch), and network connection.
  • Conversion failed: check access to the destination folder; reopen it from the Conversion panel.
  • Empty folders in the sidebar: reopen the folder via Settings → Transfer / destination to renew macOS authorization.
  • Missing overlay file: if media was moved, use “Locate file…” on the affected layer.

Logs and reports

  • Menu Help → Open logs folder…
  • Menu Help → Export diagnostic logs… (also in Settings)
  • After a crash, Oculus may offer to send a report by email to contact@picaza.fr (optional; confirm send in Mail).
